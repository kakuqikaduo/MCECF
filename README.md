# MCECF.
The core network code of MCECF has been uploaded. For the training and testing framework, we adopted the publicly available testing framework of SEIFNet. 

Therefore, the environment configuration as well as the training and testing related code can refer to SEIFNet. 

We also sincerely appreciate SEIFNet for making their network code publicly available. The source code link for SEIFNet is provided below.
